Chess Arena

A tournament between versions of the chess engine, played entirely in your browser. Every move is run from the code in this page, each game in its own background thread, and the rating table updates after every game.

Results are saved in this browser as games finish, so you can close the page and press Start later to continue.

Ratings here are relative: they show how far apart the players are, pinned to the anchor you choose below (by default: the original engine is pinned at 1000).
